# 色収差の分離距離

この色収差部分は、Boris FX Sapphireの`S_DistortChroma`に近い「レンズ勾配に沿ってスペクトル端を別量でワープする」モデルにしています。公式仕様のLens、Amount、Warp Red/Blue、Steps、Wrap=Reflectに対応し、入力画像からLens相当の輪郭勾配を自動生成しています。

以前の色収差が小さく見えた主な理由は、`色収差`が0〜100%に制限され、さらに色のサンプル距離が変位強度に比例していたためです。変位強度を小さくしたプレビューでは、色収差の端点間距離も小さくなります。

色収差の端点間距離は、マスクが1に近い場所でおおよそ次の値です。現在の既定値（赤ワープ50%、青ワープ100%）では次の式になります。

```text
端点間距離 ≈ 変位強度 × 色収差率 × |赤ワープ + 青ワープ|
```

例えば変位強度が8pxの場合:

| 色収差 | 端点間距離の目安 |
|---:|---:|
| 100% | 12px |
| 200% | 24px |
| 400% | 48px |
| 800% | 96px |

実際の出力ではRGBのスペクトル重みが隣接サンプルを混ぜるため、境界はこの値より柔らかく見えます。赤ワープと青ワープをともに100%へ設定した場合は、旧来の対称式（8px・800%なら128px）になります。今回の変更でUI範囲を0〜800%に拡張し、シェーダー側も1.0を超える値をそのまま扱うようにしました。既存の35%などの設定は同じ値のまま動作します。各タップは、流れによる基準位置に対して輪郭勾配方向へ`d × signedWarp`だけ追加オフセットし、`signedWarp`は青端の`-青ワープ`から赤端の`+赤ワープ`まで補間します。

高い値では入力ハローとテクスチャ参照範囲も広がります。境界はReflectで折り返すため、Clamp時のような端の単色化を抑えます。まず400〜600%を基準にし、800%は画面端や輪郭を大きく分離したい場合に使う想定です。`赤ワープ`/`青ワープ`を大きくすると赤青の非対称性も強くなります。
